# Proyecto-de-Evolución
Alumna: Kolmaier Caterin
Carrera: Recursos Digitales y marketing
Proyecto académico sobre la evolución del desarrollo Front End, Back End e Inteligencia Artificial como soporte al desarrollo durante 2021-2025.
## Descripción

Este proyecto académico analiza la evolución del desarrollo web durante el período 2021-2025, con énfasis en las tecnologías y herramientas utilizadas en Front End, Back End y en la Inteligencia Artificial como soporte al desarrollo.

El objetivo es identificar los principales cambios tecnológicos, tendencias y formas de utilización de estas herramientas durante el período analizado.

## Objetivos

- Analizar la evolución de las tecnologías Front End entre 2021 y 2025.
- Analizar la evolución de las tecnologías Back End entre 2021 y 2025.
- Analizar el uso de la Inteligencia Artificial como soporte al desarrollo.
- Identificar cambios y tendencias en el desarrollo web.
- Integrar los resultados de la investigación en un sitio web académico.

## Metodología

El proyecto se desarrolló mediante diferentes etapas y herramientas:

### 1. Investigación — Perplexity

Se utilizó Perplexity para realizar la investigación sobre:

- Tecnologías y herramientas Front End.
- Tecnologías y herramientas Back End.
- Inteligencia Artificial como soporte al desarrollo.

La investigación se centró en el período 2021-2025 y permitió recopilar información y fuentes para el análisis posterior.

### 2. Organización de la información — Gemini

Los resultados de la investigación fueron organizados mediante Gemini.

Se generaron:

- `01_Front_End_2021_2025.xlsx`
- `02_Back_End_2021_2025.xlsx`
- `03_IA_como_soporte_al_desarrollo_2021_2025.docx`

Estos archivos contienen la información utilizada como base para el análisis del proyecto.

### 3. Análisis — Cuaderno Gemini

Mediante Cuaderno Gemini se analizaron los archivos generados anteriormente.

El análisis permitió identificar tendencias, cambios tecnológicos y relaciones entre Front End, Back End e Inteligencia Artificial durante el período 2021-2025.

### 4. Desarrollo del sitio web — Claude

Claude se utilizó para generar el código del sitio web a partir de los resultados obtenidos durante las etapas anteriores.

El sitio presenta la información organizada en diferentes secciones relacionadas con la evolución del desarrollo web y el uso de Inteligencia Artificial como apoyo al desarrollo.

### 5. Publicación — Netlify

El sitio web fue publicado mediante Netlify para permitir su visualización en línea.

### 6. Documentación — GitHub

GitHub se utiliza para almacenar el código del sitio web y documentar el proceso realizado durante el proyecto.

## Sitio web

El sitio web del proyecto fue publicado mediante Netlify.

## Temas analizados

### Front End

Se analiza la evolución de las tecnologías y herramientas utilizadas para el desarrollo de la parte visual e interactiva de las aplicaciones web durante 2021-2025.

### Back End

Se analiza la evolución de tecnologías, herramientas y enfoques utilizados para el desarrollo de la parte del servidor, procesamiento de datos y funcionamiento interno de las aplicaciones web.

### Inteligencia Artificial como soporte al desarrollo

Se analiza la incorporación de herramientas de Inteligencia Artificial como apoyo en diferentes tareas relacionadas con el desarrollo de software, considerando sus usos, beneficios, cambios y aspectos relevantes durante 2021-2025.
